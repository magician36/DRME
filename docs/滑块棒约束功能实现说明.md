# 滑块-棒约束功能实现说明

## 功能概述

本次更新实现了完整的滑块-棒装配约束系统，包括：

1. **装配完成后自动添加约束**：当滑块与棒/螺钉装配时，自动创建轴向平移约束
2. **运动限制**：棒只允许沿滑块的孔轴方向平移，禁止旋转和其他方向平移
3. **操纵器自动裁剪**：根据约束自动禁用旋转手柄，只保留允许平移方向的手柄

## 核心改动

### 1. 数据结构扩展 (PartGraph.h)

#### 新增 MateConstraint 结构体
```cpp
struct MateConstraint
{
    std::string sliderName;   // 滑块名称
    std::string rodName;      // 棒/螺钉名称
    gp_Ax1 rodAxis;          // 约束轴（滑块的孔轴，世界坐标系）
    int holeIndex = -1;      // 使用的孔索引
};
```

**关键点**：`rodAxis` 存储的是**滑块孔轴在世界坐标系下的表示**，用于后续约束计算。

#### PartGraph 类新增方法
```cpp
void AddMate(const MateConstraint& mate);                    // 添加装配约束
const std::vector<MateConstraint>& GetMates() const;         // 获取所有约束
```

### 2. 装配对话框改进 (AssemblyDialog.cpp)

#### onFinishClicked() 完整实现

装配完成时的处理流程：

1. **判断零件类型组合**
   - 如果是滑块-棒/螺钉组合 → 执行约束装配
   - 其他组合 → 执行普通装配

2. **执行装配对齐**
   ```cpp
   PartAssembler assembler(m_graph, m_context);
   bool success = assembler.AssembleParts(rodName, sliderName, m_selectedHoleIndex);
   ```

3. **计算世界坐标系下的孔轴**
   ```cpp
   gp_Ax1 holeAxLocal = pSlider->holes[m_selectedHoleIndex].second;
   gp_Trsf Ls = pSlider->model->LocalTransformation();
   gp_Ax1 holeAxWorld(
       holeAxLocal.Location().Transformed(Ls),
       gp_Dir(holeAxLocal.Direction().Transformed(Ls))
   );
   ```

4. **创建并添加约束**
   ```cpp
   MateConstraint mc;
   mc.sliderName = sliderName;
   mc.rodName    = rodName;
   mc.rodAxis    = holeAxWorld;   // 关键：使用世界坐标系下的轴
   mc.holeIndex  = m_selectedHoleIndex;
   
   m_graph->AddMate(mc);
   ```

### 3. 操纵器约束实现 (OCCTWidget.cpp)

#### ApplyDOFProjectionForActive() - 核心约束函数

**功能**：在操纵器拖拽过程中，将变换投影到允许的自由度上

**实现原理**：

1. **计算增量变换**
   ```cpp
   gp_Trsf Lnow = m_attachedModel->LocalTransformation();
   gp_Trsf dL = m_prevL;  // 上一帧的变换
   dL.Invert(); 
   dL.Multiply(Lnow);     // dL = Lnow * Lprev^-1
   ```

2. **投影到允许轴**
   ```cpp
   gp_Vec t = dL.TranslationPart();
   Standard_Real s = t.Dot(u.XYZ());        // 投影到允许轴
   gp_Vec tProj = gp_Vec(u.XYZ()) * s;      // 只保留沿轴分量
   ```

3. **清除旋转，应用约束后的变换**
   ```cpp
   gp_Trsf dAllowed;  // 默认为单位矩阵，无旋转
   dAllowed.SetTranslationPart(tProj);
   
   gp_Trsf Lfix = m_prevL; 
   Lfix.Multiply(dAllowed);
   m_attachedModel->SetLocalTransformation(Lfix);
   ```

#### 操纵器自动裁剪

在右键菜单的"操纵"选项中，添加了根据约束定制操纵器的逻辑：

```cpp
// 1. 禁用所有平移轴
for (int i=0;i<3;++i) 
    aManipulator->SetPart(i, AIS_MM_Translation, Standard_False);

// 2. 计算允许轴在局部坐标系中的方向
int keep = chooseAxisIndex(attachedModel, allowU);

// 3. 只启用对应轴的平移手柄
aManipulator->SetPart(keep, AIS_MM_Translation, Standard_True);
```

**chooseAxisIndex()** 函数：
- 将世界坐标系的允许轴变换到模型局部坐标系
- 找出与 X/Y/Z 轴最接近的那个轴
- 返回索引 0(X) / 1(Y) / 2(Z)

### 4. 集成到操纵流程

#### 操纵器附加时
```cpp
RememberAttachedModel(attachedModel);  // 记录当前模型和初始变换
```

#### 拖拽过程中
```cpp
aManipulator->Transform(event->pos().x(), event->pos().y(), m_3dView);
ApplyDOFProjectionForActive();  // 应用约束投影
m_3dView->Redraw();
```

#### 操纵器解除时
```cpp
RememberAttachedModel(Handle(AIS_ModelWithAxis)());  // 清空引用
```

## 使用流程

1. **装配零件**
   - 在装配对话框中选择滑块和棒
   - 选择滑块上的孔
   - 点击"完成"按钮
   - 系统自动对齐并创建约束

2. **操纵棒**
   - 右键点击已装配的棒
   - 选择"操纵"
   - 观察操纵器只显示一根平移手柄（沿孔轴方向）
   - 拖拽时，棒只能沿该轴平移，无法旋转

## 技术要点

### 坐标系转换
- 孔轴从**局部坐标系**转换到**世界坐标系**存储
- 操纵时需将世界轴转换回**局部坐标系**来决定显示哪根手柄

### 变换增量投影
- 采用"上一帧变换 + 允许增量"的方式避免累积误差
- 每帧更新 `m_prevL` 为修正后的变换

### 操纵器定制
- 通过 `SetPart(index, mode, enabled)` 控制各轴手柄显示
- 不启用 `AIS_MM_Rotation` 模式即可禁用旋转

## 扩展性

当前实现专注于滑块-棒约束，可扩展支持：
- 滑块沿棒轴的平移约束
- 螺钉的旋转约束
- 多零件级联约束

## 测试建议

1. 装配滑块和棒，观察是否正确对齐
2. 右键操纵棒，检查操纵器是否只显示一根平移杆
3. 拖拽棒，验证是否只能沿孔轴方向平移
4. 保存并重新加载，检查约束是否持久化
