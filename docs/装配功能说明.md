- `Modeling\src\PartAssembler.cpp` - 实现文件

**主要功能：**

## 装配流程详解

### 用户操作步骤：
1. **A表** - 选择要装配的零件（如：滑块1）
2. **B表** - 选择可以与之装配的零件（如：棒1）
3. **C表** - 选择装配的目标孔（如：第2个RodHole）
4. **点击完成** - 执行装配

### 程序执行过程：
```
1. 获取零件B上选定孔的轴线（考虑零件的当前变换状态）
   ↓
2. 在零件A上查找匹配类型的孔
   - 优先查找相同类型的孔（RodHole 或 ScrewHole）
   - 如果没有匹配的孔，使用主轴
   ↓
3. 方向对齐
   - 检查源轴和目标轴的方向
   - 如果方向相反（点积<0），翻转源轴
   ↓
4. 构造坐标系
   - 为源孔和目标孔分别构造稳定的参考坐标系
   - 避免万向锁问题
   ↓
5. 计算变换矩阵
   - 使用 gp_Trsf::SetDisplacement() 精确计算
   - 同时处理平移和旋转
   ↓
6. 应用变换
   - 将变换应用到零件A的模型
   - 更新零件A所有孔的轴线位置
   - 刷新3D显示
   ↓
7. 记录约束
   - 记录装配关系（A装配到B）
   - 记录约束类型（RodHole 或 ScrewHole）
   - 更新连接零件列表
```

## 关键技术点

### 1. 稳定坐标系构造 (BuildFrame)
```
问题：如果孔轴方向与世界坐标系某个轴平行，叉积会失效
解决：动态选择参考方向
  - 如果孔轴Z分量不接近1，用世界Z轴作参考
  - 否则用世界X轴作参考
  - 如果还不行，用世界Y轴作参考
```

### 2. 孔轴更新
```
问题：装配后如果再次选择该零件，孔的位置是错误的
解决：每次变换后，更新所有孔轴到新坐标系
  for (auto& hole : partInfo.holes) {
      hole.second.Transform(trsf);
  }
```

### 3. 支持重复装配
```
优势：同一个零件可以多次装配到不同孔
实现：
  - 不检查是否已装配
  - 每次装配覆盖之前的变换
  - 约束关系可以重复更新
```

## 使用示例

### 在代码中直接调用：
```cpp
#include "PartAssembler.h"

// 创建装配器
PartAssembler assembler(&partGraph, context);

// 将"滑块1"装配到"棒1"的第0个孔
bool success = assembler.AssembleParts("滑块1", "棒1", 0);

if (success) {
    qDebug() << "装配成功！";
}
```

### 在对话框中使用（已集成）：
1. 用户在A/B/C表中选择
2. 点击"完成"按钮
3. 自动调用 `PartAssembler::AssembleParts()`
4. 显示装配结果

## 注意事项

### 1. 零件名称编码
- 使用 UTF-8 编码
- 名称前后空格会被自动去除
- 支持中文名称

### 2. 坐标系约定
- 孔轴方向：指向孔的内部
- 装配后两个轴线完全重合
- 右手坐标系

### 3. 错误处理
- 参数检查：零件存在性、孔索引有效性
- 异常捕获：变换失败会有提示
- 日志输出：所有关键步骤都有日志
