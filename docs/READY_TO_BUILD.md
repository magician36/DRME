## ?? 使用技巧

### 1. 重复装配
同一个零件可以多次装配到不同孔：
```cpp
assembler.AssembleParts("滑块1", "棒1", 0);  // 装配到孔0
// 稍后...
assembler.AssembleParts("滑块1", "棒1", 1);  // 重新装配到孔1
```

### 2. 装配链
可以构建装配链：
```cpp
assembler.AssembleParts("滑块1", "棒1", 0);   // 滑块装配到棒
assembler.AssembleParts("螺钉1", "滑块1", 0); // 螺钉装配到滑块
```

### 3. 调试
查看控制台输出可以了解装配细节：
- 位移距离
- 角度调整
- 孔类型匹配
